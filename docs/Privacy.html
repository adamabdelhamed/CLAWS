Privacy Policy

Effective Date: June 1, 2026

CLAWS: Command Line Advanced Warfare System ("the Game") is designed to respect your privacy. This Privacy Policy explains how data is handled when you use the Game.

  1. 1. Data Collection

    The Game does not collect, store, or transmit personally identifiable information (PII).

    The Game may collect anonymous gameplay telemetry to help improve game balance, performance, stability, and user experience. Examples may include:

    • Game session starts and ends
    • Aggregate gameplay statistics
    • Feature and menu usage
    • Performance metrics
    • Error and diagnostic information

    This telemetry is designed to be anonymous and is not intended to identify individual users.

  2. 2. Telemetry Controls

    Anonymous telemetry is enabled by default and can be disabled at any time through the Game's settings menu.

    When telemetry is disabled, the Game will stop transmitting telemetry data.

  3. 3. Local Storage

    The Game may write data to your local device for purposes such as saving settings, preferences, game progress, and telemetry preferences. This data remains on your device unless you enable external platform features such as cloud synchronization.

  4. 4. Steam Cloud Saves

    When playing the Game through Steam, save data may be stored using Steam Cloud features provided by Valve Corporation. This data is managed by Steam and subject to Steam's own privacy policy.

    The Game does not intentionally include personally identifiable information in save data.

  5. 5. Online Services

    The Game may communicate with online services solely for the purpose of transmitting anonymous telemetry and diagnostic information described in this Privacy Policy.

    The Game does not use these services to collect personally identifiable information.

  6. 6. Third-Party Platforms

    If you access the Game through a third-party platform (such as Steam), that platform may collect and process data according to its own policies. The Game does not control or have access to this data except as explicitly described in this Privacy Policy.

  7. 7. Children's Privacy

    The Game does not knowingly collect personal information from users of any age.

  8. 8. Changes to This Policy

    This Privacy Policy may be updated in the future. Any changes will be reflected on this page.

  9. 9. Contact

    If you have any questions about this Privacy Policy, you may contact claws.cli.game@gmail.com.
